# PDF TO MP3 Canvas

Text to speech, one sentence at a time. [Open example](https://pdftomp3.com/canvas/?example=1) · [Agent guide](https://pdftomp3.com/canvas/guide.html) · [Source](https://github.com/janpmz/pdf-to-mp3-canvas)

```text
Read https://pdftomp3.com/canvas/guide.html.
Explain how memory works, send the text to PDF TO MP3 Canvas, and open the returned player link.
```

Agents: follow the guide, send chapters as JSON to `https://pdftomp3.com/canvas-api/canvases`, and open the returned `url`. Keep upload and owner codes private.

No account or plugin. Anyone with the link can read the text. The user enters a Gemini key in the player and presses Play. Never send the key to the text API.
