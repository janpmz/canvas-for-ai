# PDF TO MP3 Canvas

Listen to text in the player. Sentence by sentence. No account. Gemini key required.

[Example](https://pdftomp3.com/canvas/?example=1)

Copy the prompt:

```text
Read https://pdftomp3.com/canvas/guide.html.
Explain how memory works, send the text to PDF TO MP3 Canvas, and open the returned player link.
```

Agents: follow the [guide](https://pdftomp3.com/canvas/guide.html), send chapters as JSON to `https://pdftomp3.com/canvas-api/canvases`, and open the returned `url`. Keep upload and owner codes private.

Anyone with the link can read the text. Enter the Gemini key in the player and press Play. Never send the key to the text API.
