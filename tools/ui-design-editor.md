# UI Design Editor

Edit designs together with AI. No signup.

[Example](https://uidesigneditor.com/)

Copy the prompt:

```text
Open https://uidesigneditor.com/ and read https://uidesigneditor.com/instructions.txt.
Create an editable settings screen with a profile, email alerts, and a Save button.
```

Agents: read the [guide](https://uidesigneditor.com/instructions.txt). Use browser site tools; start with `read_design`. Keep items editable, use the latest revision, and check an exported PNG. Keep the tab open.

Anyone with a Space link can edit all projects in it. Keep the full project link.
