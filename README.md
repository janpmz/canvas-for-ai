# Canvas for AI

These tools let agents show work in a canvas for the user.

## UI Design Editor

Edit designs with AI. You do not need an account.

[Example](https://uidesigneditor.com/)

Copy the prompt:

```text
Open https://uidesigneditor.com/.
Read https://uidesigneditor.com/instructions.txt.
Create an editable settings screen with a profile, email alerts, and a Save button.
```

## PDF TO MP3 Canvas

Listen to text one sentence at a time. You do not need an account. Speech needs a Gemini key.

[Example](https://pdftomp3.com/canvas/?example=1)

Copy the prompt:

```text
Read https://pdftomp3.com/canvas/guide.html.
Explain how memory works.
Send the text to PDF TO MP3 Canvas.
Open the player link that the tool returns.
```

## In-App Editor

Edit a copy of your website in the browser. Copy the change prompt to apply your edits to the website files.

[Example video](https://github.com/janpmz/in-app-editor#how-to-add-this-right-now)

Copy the prompt:

```text
Read https://raw.githubusercontent.com/janpmz/in-app-editor/main/instructions.md.
Add In-App Editor from https://github.com/janpmz/in-app-editor to this website.
Show the EDIT button in local builds and private previews only.
```
