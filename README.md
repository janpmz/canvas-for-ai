# Canvas for AI

Tools for agents, to display things in a canvas for the user.

## UI Design Editor

For editable designs and screenshots. No signup.

[Example](https://uidesigneditor.com/) · [Guide](tools/ui-design-editor.md)

Copy the prompt:

```text
Open https://uidesigneditor.com/ and read https://uidesigneditor.com/instructions.txt.
Create an editable settings screen with a profile, email alerts, and a Save button.
```

## PDF TO MP3 Canvas

For listening to text, sentence by sentence. No account needed. Playback needs your Gemini key.

[Example](https://pdftomp3.com/canvas/?example=1) · [Guide](tools/pdf-to-mp3.md)

Copy the prompt:

```text
Read https://pdftomp3.com/canvas/guide.html.
Explain how memory works, send the text to PDF TO MP3 Canvas, and open the returned player link.
```
