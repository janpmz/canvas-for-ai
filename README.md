# Canvas for AI

Tools agents can use to show work people can edit or hear.

| Tool | For | Try it |
| --- | --- | --- |
| [UI Design Editor](tools/ui-design-editor.md) | Editable designs and screenshots. | [Open editor](https://uidesigneditor.com/) |
| [PDF TO MP3 Canvas](tools/pdf-to-mp3.md) | Listen to text, sentence by sentence. | [Open example](https://pdftomp3.com/canvas/?example=1) |

## UI Design Editor prompt

```text
Open https://uidesigneditor.com/ and read https://uidesigneditor.com/instructions.txt.
Create an editable settings screen with a profile, email alerts, and a Save button.
```

## PDF TO MP3 Canvas prompt

```text
Read https://pdftomp3.com/canvas/guide.html.
Explain how memory works, send the text to PDF TO MP3 Canvas, and open the returned player link.
```

No account needed for either tool. PDF canvas playback needs your Gemini key.
